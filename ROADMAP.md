# Roadmap

Machineward is being built in public. This roadmap describes the current direction and may change as implementation and testing provide better information.

## V0 — Focused Linux prototype

- [ ] Define the agent, relay, and mobile application boundaries
- [ ] Build a desktop agent prototype
- [ ] Collect CPU, per-core, memory, swap, and process metrics
- [ ] Add a secure one-time pairing flow
- [ ] Display a basic health summary in the mobile app
- [ ] Add plain-language resource insights
- [ ] Add one safe, allowlisted process action
- [ ] Test on Pop!_OS 24.04 LTS x86_64
- [ ] Document the security release gate

## V1 — Usable personal companion

- [ ] Improve health summaries and action feedback
- [ ] Add safe power actions
- [ ] Add session revocation and recovery flows
- [ ] Support Ubuntu 24.04 LTS
- [ ] Support one current Fedora Workstation release
- [ ] Publish self-hosting documentation
- [ ] Review the complete pairing and action flow

## Later exploration

- Reconnection and offline handling
- History and alerts
- Additional Linux distributions
- Additional desktop platforms
- More safe actions where the security and product boundaries remain clear

## Explicitly out of scope for the initial versions

- Screen sharing
- Mouse and keyboard control
- Arbitrary shell commands
- File browsing or transfer
- Enterprise fleet management
