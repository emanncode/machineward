# Machineward brand assets

- `mark.svg` is the current identity direction: an interrupted boundary with a single state path. The open edge represents visibility within deliberately limited access; it avoids a generic monitor, waveform, or letter monogram.
- `avatar.svg` / `avatar.png` are square profile images using the mark without text.
- `social-card.svg` / `social-card.png` are the website link preview assets. The PNG is 1200 × 630 and is referenced by the Open Graph and X metadata in `index.html`.
- `x-header.png` is sized for an X profile header (1500 × 500).
- `linkedin-cover.png` is sized for a LinkedIn personal profile background (1584 × 396).

The social graphics use `../illustrations/open-doodles-laying.svg`, adapted from Pablo Stanley's Open Doodles under CC0. See [../illustrations/README.md](../illustrations/README.md) for the asset attribution and adaptation details.
